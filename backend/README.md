# CodeHunt backend

FastAPI API каталога задач, административного редактора и пользовательских решений. Данные хранятся в PostgreSQL, файлы — в приватном MinIO, небольшие файлы кешируются в Redis. Зависимости зафиксированы в `uv.lock`.

## Локальный запуск

Создайте корневой `.env` по `.env.example`. Из корня репозитория:

```sh
make sync-all
make up-dev-env
make migrate
make fastapi-dev
```

`make migrate` изменяет настроенную БД. Необязательная команда `make seed` создаёт демонстрационные категории, шаблоны и скрытые задачи; пользователей она не создаёт. Для показа демозадачи нужно добавить фото и снять `is_hidden`.

Swagger: `http://127.0.0.1:8000/docs`, OpenAPI: `/openapi.json`, маршруты: `/api/...`. `make up-all` запускает backend вместе с инфраструктурой в Docker. Текущий Compose предназначен для локальной разработки.

GitHub OAuth создаёт сессию на 24 часа. Администраторы определяются по подтверждённым адресам из `ADMIN_EMAILS`; пустой список не даёт административных прав. Платные задачи сейчас доступны только администраторам. Настройка OAuth и переменных — в руководстве запуска.
